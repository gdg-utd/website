# Icon sources

The monochrome social icons in this folder were downloaded from Simple Icons v16 and are stored locally.

- `discord.svg` — Discord
- `instagram.svg` — Instagram
- `linktree.svg` — Linktree

Project: https://simpleicons.org/

Repository and usage documentation: https://github.com/simple-icons/simple-icons

Simple Icons provides brand marks as a convenience. Each company's trademarks and brand guidelines still apply.
